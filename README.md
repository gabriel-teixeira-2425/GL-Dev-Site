**GL Dev — Vitrines Digitais para Pequenos Negócios**<br>
Site institucional da GL Dev, criado para apresentar os serviços de criação de sites para pequenos negócios em Pacajus e região.

**SOBRE O PROJETO**<br>
A GL Dev é uma marca pessoal criada para oferecer soluções digitais acessíveis para pequenos comércios locais. Este site funciona como vitrine dos serviços, apresentando de forma clara e objetiva o que é oferecido, os preços e como entrar em contato.

**O projeto foi desenvolvido com foco em:**
- Design elegante e profissional
- Experiência do usuário limpa e direta
- Conversão (botões de WhatsApp estrategicamente posicionados)
- Responsividade para todos os dispositivos

**TECNOLOGIAS UTILIZADAS**
- **HTML5:** Estrutura semântica e acessível
- **CSS3:** Estilização com variáveis, animações e responsividade
- **JavaScript:** Interações (menu mobile, scroll reveal, FAQ accordion, WhatsApp com mensagem personalizada)
- **Font Awesome:** Ícones vetoriais
- **Google Fonts:** Tipografia (Syne e DM Sans)
- **cloudflare:** Hospedagem

**FUNCIONALIDADES**
- Design responsivo (celular, tablet e desktop)
- Navegação fixa com destaque da seção ativa
- Menu mobile com animação hambúrguer
- Efeito de revelação suave ao rolar a página (scroll reveal)
- Seção de serviços com cards interativos
- FAQ com accordion
- Botões de WhatsApp com mensagem padrão e personalizada
- Integração com e-mail (abre Gmail)
- Rodapé com informações de contato e direitos autorais
- SEO básico (meta tags, Open Graph, Twitter Card)
